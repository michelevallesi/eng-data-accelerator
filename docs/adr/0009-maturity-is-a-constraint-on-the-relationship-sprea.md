# ADR-0009: Maturity is a constraint on the relationship, spread across six axes

- **Status:** Accepted — from PRD v1.0 (AD-09)
- **Source:** `docs/prd/` chapter "Architectural decisions"

## Decision

Maturity is a constraint on the relationship, spread across six axes

## Rationale

A single field does not survive release gates.

## Consequences for implementation

Any code, schema or configuration that contradicts this decision must be raised as a new
ADR with status `Proposed`, not implemented directly.
