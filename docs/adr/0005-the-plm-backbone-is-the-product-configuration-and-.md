# ADR-0005: The PLM backbone is the product, configuration and Change anchor

- **Status:** Accepted — from PRD v1.0 (AD-05)
- **Source:** `docs/prd/` chapter "Architectural decisions"

## Decision

The PLM backbone is the product, configuration and Change anchor

## Rationale

The product is the context in which every relationship makes sense.

## Consequences for implementation

Any code, schema or configuration that contradicts this decision must be raised as a new
ADR with status `Proposed`, not implemented directly.
