# ADR-0014: Eclipse Lyo is a technology constraint, managed as a risk

- **Status:** Accepted — from PRD v1.0 (AD-14)
- **Source:** `docs/prd/` chapter "Architectural decisions"

## Decision

Eclipse Lyo is a technology constraint, managed as a risk

## Rationale

It is the only mature OSLC implementation, with a small community.

## Consequences for implementation

Any code, schema or configuration that contradicts this decision must be raised as a new
ADR with status `Proposed`, not implemented directly.
