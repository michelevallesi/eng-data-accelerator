# ADR-0011: AI enters after the foundation, read-only; proposals stay proposals

- **Status:** Accepted — from PRD v1.0 (AD-11)
- **Source:** `docs/prd/` chapter "Architectural decisions"

## Decision

AI enters after the foundation, read-only; proposals stay proposals

## Rationale

Reproducibility, completeness and security come before productivity.

## Consequences for implementation

Any code, schema or configuration that contradicts this decision must be raised as a new
ADR with status `Proposed`, not implemented directly.
