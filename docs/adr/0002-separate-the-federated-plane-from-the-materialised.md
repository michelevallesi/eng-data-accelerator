# ADR-0002: Separate the federated plane from the materialised plane

- **Status:** Accepted — from PRD v1.0 (AD-02)
- **Source:** `docs/prd/` chapter "Architectural decisions"

## Decision

Separate the federated plane from the materialised plane

## Rationale

Truth is read live, cross-cutting questions from the projection.

## Consequences for implementation

Any code, schema or configuration that contradicts this decision must be raised as a new
ADR with status `Proposed`, not implemented directly.
