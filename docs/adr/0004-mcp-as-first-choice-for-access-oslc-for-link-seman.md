# ADR-0004: MCP as first choice for access, OSLC for link semantics

- **Status:** Accepted — from PRD v1.0 (AD-04)
- **Source:** `docs/prd/` chapter "Architectural decisions"

## Decision

MCP as first choice for access, OSLC for link semantics

## Rationale

MCP is widespread among vendors; OSLC remains the standard for links and configuration.

## Consequences for implementation

Any code, schema or configuration that contradicts this decision must be raised as a new
ADR with status `Proposed`, not implemented directly.
