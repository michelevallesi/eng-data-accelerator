# ADR-0007: Two ingestion modes: continuous projection and intentional publication

- **Status:** Accepted — from PRD v1.0 (AD-07)
- **Source:** `docs/prd/` chapter "Architectural decisions"

## Decision

Two ingestion modes: continuous projection and intentional publication

## Rationale

Governed platforms are followed, working data is not.

## Consequences for implementation

Any code, schema or configuration that contradicts this decision must be raised as a new
ADR with status `Proposed`, not implemented directly.
